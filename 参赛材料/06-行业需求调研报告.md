# 知歇 ZhiXie · 行业需求调研报告

> 调研主题：久坐人群的休息提醒需求与现有工具的接受度
> 调研对象：在校学生、远程办公 / 自由职业人群、家长
> 报告状态：**调研方案与工具已定稿；量化数据待问卷回收后填入第四、五章（标注为"待回收"的单元格）**

---

## 一、调研目的

本调研要回答三个问题：

1. **需求的真实性**：目标人群是否存在"知道该休息却常常忘记"的普遍困扰？程度如何？
2. **现有工具的缺口**：用户为什么用不长久？配置门槛与提醒的机械感各占多大权重？
3. **自然语言交互的接受度**：把"配置提醒"变成"说一句话"，用户是否愿意接受？

调研结论直接服务于产品设计：需求为真 → 产品有价值；缺口在"配置繁琐" → 强化智能体解析；缺口在"提醒机械" → 强化个性化文案。

## 六、竞品分析（功能维度）

> 以下为按公开可见的**产品功能形态**所做的对比归纳，用于说明差异化定位；正式引用前请以各产品实际版本为准。

| 对比维度 | 系统自带提醒 | 番茄钟类工具 | 知歇 |
| --- | --- | --- | --- |
| 一句话（自然语言）创建 | ✗ | ✗ | ✓ |
| 离线可用 | ✓ | 部分需要联网 | ✓（含智能体本机引擎） |
| 系统操作（锁屏 / 关机 / 重启） | 部分支持 | ✗ | ✓ |
| 全屏强制弹窗 | 部分支持 | 部分支持 | ✓ |
| 弹窗视觉可定制（底图 / 配色 / 文案） | ✗ | 有限 | ✓ |
| 无需注册账号 | ✓ | 部分需登录 | ✓ |
| 数据全部本地、无遥测 | ✓ | 部分 | ✓ |
| AI 输出经白名单校验后落库 | — | — | ✓ |
| 跨平台（Windows + macOS 同一套代码） | 各自独立 | 部分 | ✓ |

**结论**：知歇的差异化不在于"提醒"，而在于**降低创建成本**（自然语言）与**提升提醒的约束力与温度**（系统操作 + 个性化文案），同时把 AI 的不确定性用校验层兜住。

## 七、结论与产品设计映射

> 以下为调研设计阶段的预期结论方向；**实际结论需在数据回收后据实修订**。

| 预期发现 | 对应的产品设计 |
| --- | --- |
| 需求普遍存在，且"忘记"比"不想"更主要 | 以定时强制弹窗为核心干预手段，而非依赖用户自觉 |
| 配置繁琐是放弃使用的主要原因 | 智能体自然语言解析，把多步配置压缩为一句输入 |
| 文案机械导致提醒被忽略 | 依据间隔、触发次数、连续时长生成个性化建议 |
| 隐私是采纳障碍 | 默认离线可用、无账号、无遥测；云端为可选且密钥本地化 |
| 用户对 AI 解析结果存在不确定感 | 解析结果以表单可视化呈现，需用户确认后才写入；并标注结果来源 |
| 用户语言表达自由、无固定模板 | 本机规则引擎覆盖中文数字、相对时间、连写周几、日期词、系统操作词五类表达 |
