本作品为**独立立项开发的新项目**，用于参加第四届无锡市大学生创新创意创业精英赛。

- 项目使用独立的代码仓库与独立的品牌标识（应用名、图标、包名、标识符均为知歇自有的 `com.zhixie.app`）；

## 四、隐私与数据合规

| 项目 | 说明 |
| --- | --- |
| 个人信息收集 | **不收集任何个人信息**；无账号体系、无注册流程 |
| 遥测 / 埋点 | 无 |
| 广告 SDK | 无 |
| 默认网络行为 | 不联网。所有功能默认离线可用 |
| 云端功能（可选） | 仅在用户主动开启并填写密钥后启用；仅发送用户输入的那一句话，不携带任何本机数据 |
| 密钥存储 | 仅保存在本机配置文件 `agent-config.json`，不上传至任何第三方 |
| 数据存储位置 | 本机应用配置目录（Windows：`%APPDATA%\com.zhixie.app\`；macOS：`~/Library/Application Support/com.zhixie.app/`） |
| 用户数据控制权 | 支持导出 / 导入 / 重置；卸载后可自行删除配置目录 |
| 面向未成年人 | 家长场景下由家长在自有设备上设置，不涉及未成年人信息收集 |

**结论**：本作品不涉及个人信息收集与处理，符合《个人信息保护法》对"不涉及个人信息"类工具的最低合规要求。
