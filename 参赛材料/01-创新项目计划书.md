# 知歇 ZhiXie · 创新项目计划书

> 参赛组别：创新主赛道 · AIGC 创新组
> 作品形态：可运行的跨平台桌面应用（Windows x64/ARM64 安装包、Apple Silicon DMG）

---

## 一、项目概述

「知歇」是一款融合智能体的桌面休息提醒工具。用户用一句自然语言描述需求，智能体即可生成结构化的提醒规则；系统按规则在合适的时间发出全屏或窗口化弹窗，帮助使用者建立健康的工作节律。

产品口号：**知时而歇，张弛有度。**

与同类工具相比，知歇解决两个核心问题：

1. **配置门槛高**：传统提醒工具需要用户手动理解"单次/每天/每周/每月"、时间选择器、重复规则等概念，知歇允许用户直接说"每周一三五下午三点半提醒我站起来活动，顺便锁屏"，智能体负责把这句话变成可执行的规则。
2. **提醒机械、难坚持**：固定文案的提醒容易被忽略，知歇依据提醒间隔、已触发次数、连续工作时长给出个性化休息建议，语气温和、不制造焦虑。

## 二、应用场景

| 场景 | 描述 |
| --- | --- |
| 高校机房与实训室 | 学生长时间上机实训，教师希望统一引入休息节律，弹窗可自定义校风文案 |
| 备考与自学 | 番茄式节奏但不拘泥于固定 25 分钟，间隔、文案随时可调 |
| 远程办公与自由职业 | 独立开发者、设计师等久坐人群，需要"到点强制离开屏幕"的约束力（附带锁屏/关机） |
| 家庭电脑 | 家长为孩子设置使用时段，到点弹窗提醒并锁屏 |

## 三、目标用户群体

- **主要用户**：高校在校学生（备考、实训、编程）与远程办公的年轻职场人群，18—30 岁，日常连续使用电脑超过 4 小时。
- **典型画像**：知道自己"该休息"，但一进入专注状态就忘记时间；嫌传统提醒工具配置繁琐，更愿意"说一句话"。
- **安装与使用零门槛**：无需注册账号、数据全部保存在本机、无广告，安装包即为全部。

## 四、智能体开发过程

### 4.1 双通道架构

智能体采用"云端大模型 + 本机规则引擎"双通道设计：

```
用户自然语言输入
        │
        ▼
┌─────────────────┐  已配置密钥且网络可用
│  云端大模型 API   │ ────────► 生成 JSON 草稿
└─────────────────┘               │
        │ 未配置 / 断网 / 报错     ▼
        ▼                 ┌──────────────┐
┌─────────────────┐       │  字段校验层    │ 合法 → 写入提醒列表
│  本机规则引擎     │ ────► │ (validate)   │ 非法 → 过滤/回落默认值
└─────────────────┘       └──────────────┘
```

- **云端通道**：接入 OpenAI 兼容接口（默认 DeepSeek），通过系统提示词约束模型只输出规定字段的 JSON；接口地址、模型名、密钥均可在设置页修改，密钥仅保存在本机。
- **本机通道**：不依赖网络的规则引擎，覆盖高频表达——中文数字时间（"下午三点"→15:00）、相对时间（"30分钟后"）、连写周几（"每周一三五"）、日期词（今天/明天/后天）、系统操作词（锁屏/关机/重启）。
- **校验层**：无论来源，所有字段统一过校验——类型白名单、星期 0–6、日期 1–31、时间 HH:MM 合法性，非法取值被过滤或回落默认值，保证不会写坏用户数据。

### 4.2 智能体在各功能模块中的作用

| 功能模块 | 智能体的作用 |
| --- | --- |
| 定时提醒模块 | 解析自然语言为标题、类型、时间、重复规则，一键生成可用提醒 |
| 休息提醒模块 | 结合间隔、已触发次数、连续工作时长生成个性化休息建议 |
| 弹窗模块 | 支持由智能体生成弹窗文案，替代千篇一律的固定提示 |
| 数据与配置模块 | 智能体配置独立存储，与用户提醒数据隔离，互不影响 |

### 4.3 低代码/无代码使用说明

本作品的智能体编排**不需要用户编写任何代码**：

- 普通用户：无需任何配置，安装即用——智能体自动工作在本机规则引擎模式；
- 进阶用户：在"智能助手"页填写大模型平台提供的接口地址与密钥即可启用云端通道，全程为表单填写，无代码；
- 解析结果以可视化表单呈现（类型/时间/重复/系统操作），用户确认后才写入，全程所见即所得。

## 六、预期成果

1. 一款可直接安装使用的双平台桌面应用（Windows x64/ARM64 + Apple Silicon）；
2. 一套可复用的"自然语言→提醒规则"解析方案与测试用例集（前端 77 项、Rust 61 项自动化测试）；
3. 面向高校场景的休息文案模板库与使用指南。

## 七、创新点

1. **一句话生成提醒规则**：把"配置提醒"变成"说一句话"，大幅降低使用门槛；
2. **云端+本机双通道智能体**：云端提升理解能力，本机规则引擎保证离线可用与响应速度，用户无感知切换；
3. **校验优先的落地设计**：大模型输出一律过校验层再落库，规避幻觉数据污染用户配置；
4. **人机协同的开发范式**：项目由学生独立主导，借助 AIGC 工具完成跨平台工程实现，配合 138 项自动化测试形成"AI 生成 + 人工架构设计 + 测试闭环"的可验证开发流程；
5. **温和的休息倡议**：产品立场是"知时而歇"而非"效率压榨"，文案体系避免制造焦虑。

## 八、应用价值

- **健康价值**：久坐是高校学生与办公人群的高频健康风险，定时强制休息是最直接的干预手段；
- **教育价值**：为"AI 辅助开发"提供一个可检验的本科/高职教学案例——用 AI 把一个人的想法变成商业级工程质量的作品；
- **推广价值**：零账号、零联网（默认）、零广告，适合机房批量部署与家庭场景推广。
