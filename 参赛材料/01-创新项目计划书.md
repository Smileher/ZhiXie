## 一、项目概述

### 1.1 一句话定义

「知歇」是一款**融合智能体的桌面休息提醒工具**：用户用一句自然语言描述需求，智能体即可生成结构化的提醒规则；系统按规则在合适的时间发出全屏或窗口化弹窗，帮助使用者建立健康的工作节律。

产品口号：**知时而歇，张弛有度。**

### 1.2 与同类工具相比，知歇解决的两个核心问题

| 痛点 | 传统提醒工具 | 知歇的做法 |
| --- | --- | --- |
| **配置门槛高** | 需要用户手动理解"单次 / 每天 / 每周 / 每月"、时间选择器、重复规则等多个概念 | 直接说「每周一三五下午三点半提醒我站起来活动，顺便锁屏」，智能体把这句话变成可执行规则 |
| **提醒机械、难坚持** | 固定文案反复弹出，几次之后被大脑自动忽略 | 依据提醒间隔、已触发次数、连续工作时长生成个性化休息建议，语气温和、不制造焦虑 |

### 1.3 产品定位

- **形态**：桌面客户端（Windows / macOS），本地安装、托盘常驻、支持开机自启；
- **数据**：全部保存在本机，无需注册账号，默认不联网、不采集数据、无广告；
- **门槛**：普通用户装完即用（本机规则引擎模式）；进阶用户填一张表单即可启用云端大模型；
- **立场**：产品立场是"知时而歇"而非"效率压榨"，文案体系刻意避免制造焦虑，不强调加班或提高工作强度。

## 二、应用场景

| 场景 | 描述 | 知歇对应能力 |
| --- | --- | --- |
| **高校机房与实训室** | 学生长时间上机实训，教师希望统一引入休息节律 | 预设学生场景锚点（吃饭 / 下课 / 周末）；弹窗文案可自定义校风文案；零账号便于机房批量部署 |
| **备考与自学** | 番茄式节奏但不拘泥于固定 25 分钟 | 休息间隔可自由设定（默认 40 分钟），提示语随时可改 |
| **远程办公与自由职业** | 独立开发者、设计师等久坐人群，需要"到点强制离开屏幕"的约束力 | 可附加锁屏 / 关机 / 重启，触发前有 60 秒可撤销倒计时 |
| **家庭电脑** | 家长为孩子设置使用时段 | 每天 / 每周 / 每月重复锚点，到点弹窗并可锁屏 |
| **宿舍作息管理** | 到点结束学习、准备休息 | 智能体直接理解「每天晚上十一点提醒我锁屏睡觉」 |

## 三、目标用户群体

### 3.1 主要用户

- **在校学生（备考、实训、编程）** 与 **年轻职场人群（远程办公、自由职业）**；
- 年龄区间约 18—30 岁，日均连续使用电脑超过 4 小时；
- **典型画像**：知道自己"该休息"，但一进入专注状态就忘记时间；嫌传统提醒工具配置繁琐，更愿意"说一句话"。

### 3.2 次要用户

- **家长**：需要为孩子的电脑使用时段设置到点提醒与锁屏；
- **教师 / 机房管理员**：需要在机房统一施加休息节律。

### 3.3 用户获得的价值

1. **零门槛起步**：无需注册、无需读说明书，安装包即为全部；
2. **零学习成本配置**：把"配置提醒"变成"说一句话"；
3. **零成本离线可用**：不联网也能完整使用，网络只是"可选增强"。

## 四、智能体开发过程（核心）

### 4.1 双通道架构

智能体采用"**云端大模型 + 本机规则引擎**"双通道设计，用户对通道切换无感知：

```
                       用户自然语言输入
                              │
                              ▼
                  ┌───────────────────────┐
        已配置密钥 │    云端大模型通道      │  HTTPS 调用 OpenAI 兼容接口
        且网络可用 │  （默认 DeepSeek）     │  temperature 0.2 / 40s 超时
                  └───────────┬───────────┘
                              │ 生成 JSON 草稿
      未配置 / 断网 / 报错     │
                  ┌───────────▼───────────┐
                  │    统一字段校验层       │  validate_draft（白名单）
                  │  类型 / 时间 / 星期 /   │
                  │  日期 / 系统操作        │
                  └───────────┬───────────┘
                              │ 合法 → 写入提醒列表
                 ┌────────────┴────────────┐
                 │                         │
                 ▼                         ▼
   ┌───────────────────────────┐   ┌──────────────────┐
   │  本机规则引擎（离线兜底）   │   │   提醒数据 / 弹窗 │
   │  中文数字时间 / 相对时间 /  │   └──────────────────┘
   │  连写周几 / 日期词 / 系统操作│
   └───────────────────────────┘
```

**三条设计原则：**

1. **云端提升上限**：通过系统提示词约束模型只输出规定字段的 JSON，`temperature` 设为 0.2 以保证稳定性，40 秒超时保护避免界面卡死；
2. **本机保底可用**：未配置密钥、网络不通或接口报错时，自动切换到纯 Rust 实现的本机规则引擎，**功能不中断**，界面会明确提示"云端不可用，已自动切换本机规则引擎"；
3. **校验优先落库**：无论结果来自云端还是本机，字段统一过白名单校验后才写入数据，**规避大模型幻觉污染用户配置**。

### 4.2 本机规则引擎覆盖的高频表达

| 表达类型 | 示例输入 | 解析结果 |
| --- | --- | --- |
| 中文数字时间 | 「每天**下午三点**提醒我喝水」 | `daily` · `15:00` |
| 相对时间 | 「**30分钟后**提醒我休息」 | `once` · 当前时间 +30 分钟 |
| 连写周几 | 「**每周一三五** 17:30 提醒我锁屏」 | `weekly` · `[1,3,5]` |
| 日期词 | 「**明天**早上八点提醒我交作业」 | `once` · 次日 `08:00` |
| 系统操作词 | 「晚上11点**关机**」「明早**重启**电脑」 | 识别为 `shutdown` / `restart` / `lock` |
| 无关键词兜底 | 「记得寄快递」 | `once` · 近期时间点，标题保留原句 |

### 4.3 校验层规则（`validate_draft`）

| 字段 | 白名单 / 约束 | 非法时的处理 |
| --- | --- | --- |
| `reminder_type` | 仅 `once` / `daily` / `weekly` / `monthly` | 回落为 `once` |
| `time` | 必须为合法 `HH:MM`（小时 ≤ 23、分钟 ≤ 59） | 回落为 `09:00` |
| `weekdays` | 整数且限定 `0–6` | 越界值被过滤 |
| `month_days` | 整数且限定 `1–31` | 越界值被过滤 |
| `power_action` | 仅 `lock` / `shutdown` / `restart` / 空 | 非法值置空 |
| `title` | 非空 | 回落为用户原始输入 |
| `popup_message` | 去除首尾空白 | 为空则不出现在结果中 |

> 该行为由单元测试 `cloud_drafts_are_validated` 覆盖：构造"非法类型 + 非法时间 + 越界星期 + 越界日期 + 非法系统操作"的脏数据，验证全部被正确过滤或回落。

### 4.4 容错设计

- **JSON 提取容错**：大模型返回带 ``` 代码块包裹、或夹杂解释性文字时，仍能准确提取出 JSON 对象（测试 `json_extraction_tolerates_code_fences`）；
- **配置隔离**：智能体配置独立存放在 `agent-config.json`，**不进入主数据结构**，因此不影响用户数据的版本号，也不会因智能体配置损坏而波及提醒数据；
- **密钥本地化**：接口地址、模型名、API 密钥仅保存在本机配置文件，不上传到任何第三方。

### 4.5 智能体在各功能模块中的作用

| 功能模块 | 智能体的作用 |
| --- | --- |
| 时间锚点（定时提醒）模块 | 把自然语言解析为标题、类型、时间、重复规则，一键生成可用提醒 |
| 休息节律模块 | 结合间隔、已触发次数、连续工作时长生成个性化休息建议 |
| 弹窗模块 | 支持由智能体生成弹窗文案，替代千篇一律的固定提示 |
| 数据与配置模块 | 智能体配置独立存储，与用户提醒数据隔离，互不影响 |

## 五、低代码 / 无代码使用说明

本作品的智能体编排**不需要用户编写任何代码**，分为两档：

| 用户类型 | 使用方式 | 是否需要代码 |
| --- | --- | --- |
| 普通用户 | 安装即用，智能体自动工作在本机规则引擎模式，零配置、零联网 | 否 |
| 进阶用户 | 在「智能体 → 接入口」填写大模型平台提供的接口地址、模型名与密钥，全程为表单填写 | 否 |

**低代码特征体现在三处：**

1. **可视化配置**：接口地址、模型名、密钥三项表单即完成"接入编排"，无需编写任何请求代码；
2. **可视化确认**：解析结果以表单呈现（类型 / 时间 / 重复 / 系统操作 / 弹窗文案），用户确认后才写入，全程所见即所得；
3. **可视化调校**：弹窗的背景图、缩放、偏移、文字颜色、标题字号、遮罩透明度、淡入效果均可在设置页实时预览调整。

## 八、创新点

1. **一句话生成提醒规则**：把"配置提醒"变成"说一句话"，大幅降低使用门槛；
2. **云端 + 本机双通道智能体**：云端提升理解能力，本机规则引擎保证离线可用与响应速度，用户无感知切换；
3. **校验优先的落地设计**：大模型输出一律过白名单校验层再落库，规避幻觉数据污染用户配置；
4. **人机协同的开发范式**：项目由学生独立主导，借助 AIGC 工具完成跨平台工程实现，并以 138 项自动化测试形成"AI 生成 + 人工架构设计 + 测试闭环"的可验证开发流程；
5. **温和的休息倡议**：产品立场是"知时而歇"而非"效率压榨"，文案体系避免制造焦虑。

## 十、风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 大模型输出不稳定 / 幻觉 | 可能生成不存在的提醒规则 | 统一白名单校验层，非法字段过滤或回落；结果需用户确认后才写入 |
| 云端接口不可用 | 联网功能失效 | 本机规则引擎自动接手，功能不中断，界面明确提示结果来源 |
| 接口费用与密钥泄露 | 用户成本与隐私风险 | 默认关闭云端；密钥仅存本机；仅发送用户输入的那一句话，不携带任何本机数据 |
| 提醒被用户忽略 | 产品价值打折 | 全屏弹窗 + 系统通知 + 个性化文案，并可附加锁屏 / 关机形成约束力 |
| 平台差异导致行为不一致 | 双端体验割裂 | 双平台真机验证 + 138 项自动化测试；针对 Windows / macOS 分别实现关键能力 |
