# 知歇 ZhiXie · 使用说明

> 适用版本：1.0.0（Windows x64/ARM64、Apple Silicon macOS）

---

## 一、安装与首次启动

1. 运行安装包（Windows 为 NSIS 安装程序，macOS 为 DMG，将应用拖入"应用程序"文件夹）。
2. 首次启动后应用主窗口出现，同时驻留系统托盘。
3. 关闭窗口默认最小化到托盘，不会退出；完整退出请通过托盘菜单。
4. 首次使用已内置三条学生场景预设（下课吃饭、课程结束回宿舍、周五放学关机），默认关闭，可按需开启。

## 二、用户操作流程

### 2.1 主界面结构

顶部为导航栏（顶栏式布局），从左到右依次是：

| 导航项 | 功能 |
| --- | --- |
| 休息节律 | 开关休息提醒、设置间隔与歇息文案、查看本轮休息进度 |
| 时间锚点 | 管理所有定时提醒（单次/每天/每周/每月），可附带关机、锁屏等动作 |
| 智能体 | 一句话生成提醒规则、个性化休息建议（推荐入口，带常亮标识） |
| 偏好调校 | 节律、舞台、系统、数据四个分区 |
| 关于 | 版本信息、AIGC 能力与团队介绍 |

### 2.2 创建一条提醒（常规方式）

1. 进入「时间锚点」→ 点击「新建锚点」；
2. 填写提醒内容，选择重复方式（单次 / 每天 / 每周 / 每月）；
3. 按类型选择触发时间或重复规则；
4. 可选：附加到点动作（锁屏 / 关机 / 重启），触发时会有 60 秒可撤销倒计时；
5. 保存后列表即显示该提醒及下次触发时间。

### 2.3 创建一条提醒（智能体方式，推荐）

1. 进入「智能体」页，顶部展示当前引擎状态（云端大模型 / 本机引擎）；
2. 在输入框用一句话描述需求，或直接点击下方示例话术：
   - 「每天早上八点提醒我背二十个单词」
   - 「每周一三五下午五点提醒我去操场跑步」
   - 「三十分钟后锁屏，让我休息一下」
3. 点击「解析需求」；
4. 核对解析结果（类型、时间、重复、系统动作、弹窗文案）；
5. 点击「收进时间线」，应用自动跳转到时间锚点页并提示已收进。

### 2.4 休息节律

1. 进入「休息节律」打开开关；
2. 设置间隔分钟数与歇息文案；
3. 到点后弹出整屏或小窗弹窗，可选择"稍后提醒"或直接结束休息；
4. 进度条实时显示本轮剩余时间。

### 2.5 偏好调校（四个分区）

| 分区 | 内容 |
| --- | --- |
| 节律 | 提醒如何打断你：整屏覆盖、始终浮在最前、再推一条系统通知、底图渐入 |
| 舞台 | 提醒长什么样：明暗主题、主色调、弹窗底图（内置校徽默认图，可自选）、底图铺法、暗场浓度、提醒文字颜色与字号，全部改动在「实时预览」即时可见（整屏 / 小窗两种预览） |
| 系统 | 界面语言、随系统开机、静默启动 |
| 数据 | 导出 / 导入 JSON 备份、恢复出厂参数 |

## 三、智能体交互指南

### 3.1 说话方式

智能体理解自然语言，以下表达均可正确解析：

| 你说 | 智能体生成 |
| --- | --- |
| 每周一三五下午三点半提醒我站起来活动，顺便锁屏 | 每周提醒，周一/三/五 15:30，附加锁屏 |
| 30分钟后提醒我休息 | 单次提醒，30 分钟后 |
| 明天早上八点提醒我交作业 | 单次提醒，明天 08:00 |
| 工作日 17:30 关机 | 每周提醒，周一至五 17:30，附加关机 |
| 每月 1 号早上九点提醒我交房租 | 每月提醒，1 号 09:00 |

要点：**把时间、重复规律和要做的事说清楚即可**，语序自由，无需关键词模板。

### 3.2 使用与接入口分离

智能体页顶部有「使用 / 接入口」两个分区：

- **使用**：输入需求、解析、查看结果与休息建议，日常只用这一页；
- **接入口**：云端大模型的连接配置，配一次即可，日常无需再碰。

### 3.3 休息建议

「使用」分区下方是休息建议卡片，点击「换一条」即可生成。建议依据提醒间隔、已触发次数与连续工作时长生成，语气温和、可执行。

### 3.4 配置云端大模型（可选）

默认情况下智能体完全工作在本机，**不联网、不需要任何账号**。若希望获得更强的语言理解能力：

1. 进入「智能体 → 接入口」；
2. 打开「接入云端大模型」；
3. 填写大模型平台提供的接口地址（默认 DeepSeek）、模型名称与 API 密钥；
4. 点击「保存接入口」。

说明：

- 密钥仅保存在本机配置文件 `agent-config.json`，不上传到任何第三方；
- 云端通道不可用（断网、密钥失效、接口异常）时自动切回本机规则引擎，界面会提示"云端没有响应，已由本机规则引擎接管"；
- 解析结果由谁产生（云端大模型 / 本机引擎）会在结果旁明确标注。

### 3.5 智能体结果的可靠性

无论解析结果来自云端还是本机，均会经过统一校验：类型仅接受四种合法值、星期限定 0–6、日期限定 1–31、时间必须为合法 HH:MM；不合法的字段会被过滤或回落为默认值，**不会把错误数据写入你的提醒列表**。

## 四、常见问题

| 问题 | 处理 |
| --- | --- |
| 弹窗没有出现 | 检查「偏好调校 → 节律」中系统通知是否开启（macOS 需在系统设置中允许通知权限） |
| 开机自启设置失败 | 见「偏好调校 → 系统」：macOS 需先将应用移入「应用程序」文件夹；Windows 若提示冲突，先在旧副本中关闭自启 |
| 智能体解析结果不对 | 直接在结果页核对字段后选择不加入；或换一种更明确的时间表达 |
| 想完全离线使用 | 不开启接入口的云端开关即可，全部功能均可离线使用 |
| 界面颜色不喜欢 | 「偏好调校 → 舞台」提供 8 种主色调与明暗主题，默认为科技蓝 |
