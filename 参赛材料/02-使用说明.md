# 知歇 ZhiXie · 使用说明

> 适用版本：1.0.0
> 支持平台：Windows 10 / 11（x64、ARM64）· macOS（Apple Silicon）
> 适用对象：终端用户、指导教师、评审专家

---

## 一、安装与首次启动

1. 运行安装包。Windows 为 NSIS 安装程序（可选择简体中文 / English 安装界面），macOS 为 DMG，将「知歇」拖入「应用程序」文件夹。
2. 首次启动后出现主窗口，同时驻留系统托盘（菜单栏）。
3. **关闭窗口默认最小化到托盘**，不会退出应用；要完整退出请使用托盘菜单中的退出项。
4. 首次使用已内置三条**学生场景预设锚点**，默认处于关闭状态，可按需开启：

| 预设锚点 | 时间 | 重复 | 附加操作 |
| --- | --- | --- | --- |
| 下课啦，先去食堂吃口热的。 | 11:50 | 每天 | 锁屏 |
| 今天的课结束了，回宿舍好好歇歇。 | 17:30 | 周一至周四 | 锁屏 |
| 一周的课上完了，好好过周末。 | 17:30 | 周五 | 关机 |

> 预设的设计考虑：周五的关机不与周一至周四的锁屏重叠，避免同一时刻触发多个系统操作。

---

## 二、界面总览

应用采用**顶栏胶囊导航**，共五个入口：

| 导航项（中文） | 导航项（英文） | 作用 |
| --- | --- | --- |
| **休息节律** | Rhythm | 开关休息提醒、设置间隔与提示语、查看本轮休息进度 |
| **时间锚点** | Anchors | 管理所有定时提醒（单次 / 每天 / 每周 / 每月） |
| **智能体** | Agent | 一句话生成提醒、休息建议、云端大模型接入口 |
| **偏好调校** | Tuning | 节律 / 舞台 / 系统 / 数据 四组设置 |
| **关于** | About | 版本信息、产品介绍、开发团队与指导教师 |

顶栏左侧为品牌标识与口号，右侧显示当前版本号。

## 三、创建一条提醒

### 3.1 常规方式（手动配置）

1. 进入「**时间锚点**」→ 点击「添加锚点」；
2. 填写标题，选择类型（单次 / 每天 / 每周 / 每月）；
3. 按类型选择触发时间或重复规则：
   - **单次**：选择具体日期时间；
   - **每天**：选择每日触发时刻；
   - **每周**：勾选一个或多个星期；
   - **每月**：选择一个或多个日期；
4. 可选：附加系统操作（锁屏 / 关机 / 重启），触发时会有 **60 秒可撤销倒计时**；
5. 保存后，列表即显示该锚点及其下次触发时间。

### 3.2 智能体方式（推荐，一句话搞定）

1. 进入「**智能体**」→ 在「使用」分区输入一句话描述需求；
2. 点击「解析需求」（也可用 `Cmd/Ctrl + Enter` 快捷提交）；
3. 检查解析结果，结果区会列出：类型、时间、重复、系统操作、弹窗文案，并**标注结果来源是"云端大模型"还是"本机引擎"**；
4. 确认无误后点击「加入时间锚点」，应用自动跳转到时间锚点页并提示已加入。

**示例话术：**

| 你说 | 智能体会生成 |
| --- | --- |
| 每周一三五下午三点半提醒我站起来活动，顺便锁屏 | 每周提醒，周一 / 周三 / 周五 15:30，附加锁屏 |
| 30分钟后提醒我起来接水 | 单次提醒，30 分钟后 |
| 明天早上八点提醒我交作业 | 单次提醒，次日 08:00 |
| 每天下午三点提醒我喝水 | 每天提醒，15:00 |
| 每月 1 号早上九点提醒我交房租 | 每月提醒，1 号 09:00 |
| 晚上十一点提醒我锁屏睡觉 | 每天提醒，23:00，附加锁屏 |

**要点**：把**时间、重复规律、要做的事**说清楚即可，语序自由，无需套用固定模板。

## 四、休息节律

1. 进入「**休息节律**」打开开关（默认开启，间隔 40 分钟）；
2. 设置**间隔分钟数**与**提示语**（提示语即弹窗正中央显示的那句话）；
3. 到点后弹出全屏（或窗口化）弹窗，可选择「稍后提醒」或直接结束本次休息；
4. 界面上以进度条实时显示本轮剩余时间。

## 五、偏好调校（四组设置）

设置页按用途分为四组，每组附一句话说明：

### 5.1 节律 —— 决定提醒以什么方式打断你

- 整屏覆盖（全屏弹窗 / 窗口化弹窗）
- 始终浮在最前
- 系统通知
- 底图渐入

### 5.2 舞台 —— 决定提醒画面长什么样

- 主题（深色 / 浅色 / 跟随系统）
- 主色调
- 背景图（更换 / 恢复默认）
- 文字颜色与标题字号
- 遮罩透明度
- **实时预览**：以上改动在预览区即时可见

### 5.3 系统 —— 开机、语言与启动方式

- 界面语言（简体中文 / English，切换即时生效）
- 开机自启
- 静默启动

### 5.4 数据 —— 备份、迁移与恢复默认

- 导出全部配置与锚点为 JSON 备份文件
- 从备份文件恢复
- 一键重置全部设置

## 六、智能体交互指南（重点）

### 6.1 两种工作模式

| 模式 | 触发条件 | 特点 |
| --- | --- | --- |
| **本机引擎模式** | 默认，未启用云端 | 不联网、不需要账号、响应快，面向中文口语表达优化 |
| **云端大模型模式** | 用户主动开启并填写密钥 | 语言理解能力更强，可覆盖更自由的表达方式 |

页面顶部有状态胶囊实时显示当前模式（「本机引擎」/「云端大模型」）。

### 6.2 配置云端大模型（可选）

1. 进入「**智能体**」→ 切换到「**接入口**」分区；
2. 打开「启用云端大模型」开关；
3. 填写三项表单：
   - **接口地址**：默认 `https://api.deepseek.com/chat/completions`
   - **模型名称**：默认 `deepseek-chat`
   - **API 密钥**：以大模型平台提供者为准（输入框为密码型，不明文显示）
4. 点击「保存配置」。

**说明：**

- 密钥仅保存在本机配置文件 `agent-config.json`，不上传到任何第三方；
- 云端通道不可用（断网、密钥失效、接口异常）时会**自动切回本机规则引擎**，界面提示"云端不可用，已自动切换本机规则引擎"；
- 解析结果由谁产生（大模型 / 本机引擎）会在结果旁明确标注；
- 接口地址兼容任何 OpenAI 格式的对话补全接口，不限于默认服务商。

### 6.3 休息建议

「智能体」页下方是休息建议卡片，点击「换个建议」即可生成一条。建议依据**提醒间隔、已触发次数、连续时长**生成，语气温和、可执行，例如：

> 你已经连着学了 90 分钟，先站起来走几步，喝口水再回来。

### 6.4 解析结果的可靠性

无论解析结果来自云端还是本机，均会经过统一校验：

| 校验项 | 规则 |
| --- | --- |
| 类型 | 仅接受 单次 / 每天 / 每周 / 每月 四种合法值 |
| 星期 | 限定 0–6，越界被过滤 |
| 日期 | 限定 1–31，越界被过滤 |
| 时间 | 必须为合法 `HH:MM` |
| 系统操作 | 仅接受 锁屏 / 关机 / 重启 |

不合法的字段会被过滤或回落为默认值，**不会把错误数据写入你的锚点列表**。

## 七、数据与隐私

| 项目 | 说明 |
| --- | --- |
| 数据存放位置 | 本机应用配置目录（Windows：`%APPDATA%\com.zhixie.app\`；macOS：`~/Library/Application Support/com.zhixie.app/`） |
| 主数据文件 | `zhixie.json`（设置与锚点） |
| 智能体配置 | `agent-config.json`（独立存放，与主数据隔离） |
| 弹窗背景图 | `popup-background.img` |
| 联网行为 | 默认不联网；仅当用户主动启用云端大模型后，才会发送用户输入的那一句话 |
| 数据采集 | 无遥测、无广告 SDK、不采集任何用户数据 |
| 备份迁移 | 设置 →「数据」可导出 / 导入 JSON 备份，跨设备迁移无损 |

## 八、常见问题（FAQ）

| 问题 | 处理方式 |
| --- | --- |
| 弹窗没有出现 | 检查「偏好调校 → 节律」中系统通知是否开启；macOS 还需在「系统设置 → 通知」中允许知歇发送通知 |
| 开机自启设置失败 | macOS 需先将应用移入「应用程序」文件夹；Windows 若提示冲突，请在旧副本中先关闭自启 |
| 智能体解析结果不对 | 直接在结果页核对字段后选择不加入；或改用更明确的时间表达（如"下午三点半"而非"下午"） |
| 想完全离线使用 | 不开启云端开关即可，全部功能均可离线使用 |
| 提醒触发后想取消关机 / 锁屏 | 弹窗触发后有 60 秒可撤销倒计时，倒计时结束前可以取消 |
| 更换了电脑，如何迁移 | 在旧设备「数据」中导出 JSON，在新设备同一位置导入 |
| 关闭窗口后应用不见了 | 这是设计行为：默认最小化到托盘。请使用托盘菜单重新打开主窗口 |
| 系统操作执行失败 | 弹窗会保留并提供重试，不会静默丢弃 |

---

## 九、卸载

- **Windows**：设置 → 应用 → 找到「知歇」→ 卸载。若曾开启开机自启，安装程序会清理对应注册表项。
- **macOS**：将「知歇」从「应用程序」拖入废纸篓；如需彻底清理，可一并删除 `~/Library/Application Support/com.zhixie.app/` 目录（内含你的锚点与设置数据，删除前建议先导出备份）。
