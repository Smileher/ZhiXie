# 知歇 ZhiXie · 使用说明

> 适用版本：1.0.0（Windows x64/ARM64、Apple Silicon macOS）

---

## 一、安装与首次启动

1. 运行安装包（Windows 为 NSIS 安装程序，macOS 为 DMG，将应用拖入"应用程序"文件夹）。
2. 首次启动后应用出现在屏幕主窗口，同时驻留系统托盘。
3. 关闭窗口默认最小化到托盘，不会退出；完整退出请通过托盘菜单。

## 二、用户操作流程

### 2.1 主界面结构

左侧为导航栏，自上而下依次是：

| 导航项 | 功能 |
| --- | --- |
| 休息提醒 | 开关休息提醒、设置间隔与提示语、查看本轮休息进度 |
| 定时提醒 | 管理所有定时提醒（单次/每天/每周/每月） |
| 参数设置 | 通用、外观、弹窗、通知、数据五个分区 |
| 智能助手 | 自然语言生成提醒、休息建议、智能体配置 |
| 关于 | 版本信息与产品介绍 |

### 2.2 创建一条提醒（常规方式）

1. 进入「定时提醒」→ 点击「添加提醒」；
2. 填写标题，选择类型（单次 / 每天 / 每周 / 每月）；
3. 按类型选择触发时间或重复规则；
4. 可选：附加系统操作（锁屏 / 关机 / 重启），触发时会有 60 秒可撤销倒计时；
5. 保存后列表即显示该提醒及下次触发时间。

### 2.3 创建一条提醒（智能体方式，推荐）

1. 进入「智能助手」；
2. 在输入框用一句话描述需求，例如：
   - 「每天晚上十一点提醒我锁屏睡觉」
   - 「30分钟后提醒我起来接水」
   - 「每月 1 号早上九点提醒我交房租」
3. 点击「解析需求」；
4. 检查解析结果（类型、时间、重复、系统操作、弹窗文案）；
5. 点击「加入定时提醒」，应用自动跳转到定时提醒页并提示已加入。

### 2.4 休息提醒

1. 进入「休息提醒」打开开关；
2. 设置间隔分钟数与提示语；
3. 到点后弹出全屏/窗口化弹窗，可选择"稍后提醒"或直接结束休息；
4. 进度条实时显示本轮剩余时间。

### 2.5 个性化弹窗

进入「参数设置 → 弹窗」：可更换背景图、调整缩放与偏移、设置文字颜色与标题字号、遮罩透明度与淡入效果，所有改动在预览区实时可见。

### 2.6 数据管理

进入「参数设置 → 数据」：支持导出全部配置与提醒为 JSON 备份文件，以及从备份恢复；也可一键重置全部设置。

## 三、智能体交互指南

### 3.1 说话方式

智能体理解自然语言，以下表达均可正确解析：

| 你说 | 智能体生成 |
| --- | --- |
| 每周一三五下午三点半提醒我站起来活动，顺便锁屏 | 每周提醒，周一/三/五 15:30，附加锁屏 |
| 30分钟后提醒我休息 | 单次提醒，30 分钟后 |
| 明天早上八点提醒我交作业 | 单次提醒，明天 08:00 |
| 工作日 17:30 关机 | 每周提醒，周一至五 17:30，附加关机 |
| 每月 1 号早上九点提醒我交房租 | 每月提醒，1 号 09:00 |

要点：**把时间、重复规律和要做的事说清楚即可**，语序自由，无需关键词模板。

### 3.2 休息建议

「智能助手」页下方是休息建议卡片，点击「换个建议」即可生成。建议依据提醒间隔、已触发次数与连续工作时长生成，语气温和、可执行。

### 3.3 配置云端大模型（可选）

默认情况下智能体完全工作在本机，**不联网、不需要任何账号**。若希望获得更强的语言理解能力：

1. 进入「智能助手 → 智能体配置」；
2. 打开「启用云端大模型」；
3. 填写大模型平台提供的接口地址（默认 DeepSeek）、模型名称与 API 密钥；
4. 点击「保存配置」。

说明：

- 密钥仅保存在本机配置文件 `agent-config.json`，不上传到任何第三方；
- 云端通道不可用（断网、密钥失效、接口异常）时自动切回本机规则引擎，界面会提示"云端不可用，已自动切换本机规则引擎"；
- 解析结果由谁产生（大模型/本机引擎）会在结果旁明确标注。

### 3.4 智能体结果的可靠性

无论解析结果来自云端还是本机，均会经过统一校验：类型仅接受四种合法值、星期限定 0–6、日期限定 1–31、时间必须为合法 HH:MM；不合法的字段会被过滤或回落为默认值，**不会把错误数据写入你的提醒列表**。

## 四、常见问题

| 问题 | 处理 |
| --- | --- |
| 弹窗没有出现 | 检查「参数设置 → 通知」中系统通知权限是否开启（macOS 需在系统设置中允许） |
| 开机自启设置失败 | macOS 需先将应用移入「应用程序」文件夹；Windows 若提示冲突，先在旧副本中关闭自启 |
| 智能体解析结果不对 | 直接在结果页核对字段后选择不加入；或改用更明确的时间表达 |
| 想完全离线使用 | 不开启云端开关即可，全部功能均可离线使用 |
