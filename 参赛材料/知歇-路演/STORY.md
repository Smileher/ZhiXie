# STORY.md — 知歇 ZhiXie 路演演示文稿

## ① 用户意图对齐

**目标受众**：第四届无锡市大学生创新创意创业精英赛的评审专家（决赛路演答辩现场）。同时兼顾网络评审阶段「不看演示也能独立读懂」的阅读需求。

**核心目标**：讲完后希望评委相信三件事——① 这是一个**真实可用**的双平台桌面产品，不是概念稿；② 它的智能体设计是**有工程纵深**的（双通道 + 校验优先），而不是"调了个 API"；③ 它符合 AIGC 创新组对"智能体在各模块中的作用"与"低代码/无代码"的要求。记住一句话：**知时而歇，张弛有度**。行动：给出高分，并认可其可推广性。

**PPT 长度**：18 页。Hero 页配额按 18 页取 **4 页（22%）**。

**视觉调性**：暗色科技克制 / 静谧健康感 / 高对比大数字 / 一次只说一件事。

**内容边界**：
- **必讲**：一句话生成规则、云端+本机双通道、校验层、138 项测试、双平台、隐私零采集、低代码说明。
- **不讲**：代码细节实现、具体接口参数、内部文件名、测试用例逐个罗列。
- **禁碰**：任何"提高效率 / 加班 / 压榨时间"的表述；任何未经核实的第三方统计数据；任何未回收的调研数字（不得编造）。
