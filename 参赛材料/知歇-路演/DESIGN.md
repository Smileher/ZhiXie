## 0. 视觉语言

**图形语言 + 界面截图**混合：
1. 结构性图形用内联 `<svg>`：架构、流程、对照、时间轴、光弧、巨型数字、表格。
2. 凡是讲「软件长什么样、怎么用」的页面用**截图占位框**（8 处，含 3 处数据图占位）。
3. 不使用摄影 / 插画 / 3D 素材。

## 2. 配色系统（4 个 hex，不再增加）

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| 主色 · 底色 | `#0B1220` | 页面背景 |
| 辅色 · 面层 | `#1B2740` | 卡片背景、面板 |
| 强调色 | `#4FE0B0` | 导航高亮、章标签、巨型数字、关键结论、序号、占位框描边 |
| 文本主色 | `#E8EEF7` | 标题与正文 |

次级文本用 `#E8EEF7` + `opacity`（正文 0.8 / 注解 0.6 / 页脚 0.45）。描边 `rgba(232,238,247,0.14)`。禁止纯黑 / 纯红 / 纯绿 / 金色。

- 强调色：常规页 ≤ 8%，Hero 页 15–18%（P16 / P22 / P29）。
- 渐变仅用于：卡片顶部 4px 装饰条、巨型数字下短条、封面/结尾光弧；全篇 ≤ 6 次，`linear-gradient(135deg, #4FE0B0 0%, #2E9E8F 100%)`。
- 卡片浮起 `boxShadow: '0 6px 24px rgba(0,0,0,0.35)'`，全篇 ≤ 4 处。

| 组件 | 写法 |
| :--- | :--- |
| 普通卡 | `background:'#1B2740', border:'1px solid rgba(232,238,247,0.12)', borderRadius:12` |

| 分隔线 | `rgba(232,238,247,0.10)`（行间）/ `0.14`（导航底边） |

## 4. 顶部导航条规范（本版核心）

8 章固定顺序与名称（不得增减改名）：

```
01 项目背景   02 目标用户群体   03 应用场景   04 智能体开发过程
05 实施计划   06 预期成果       07 创新点     08 应用价值
```

- 位置：内容页顶部 N 区，`flexDirection:'row'`，左 logo、右章名组。
- 章名写法：`<Text style={{ fontSize:15, color:'#4FE0B0', fontWeight:'bold' }}>当前章</Text>`，其余 `<Text style={{ fontSize:15, color:'#E8EEF7', opacity:0.5 }}>其他章</Text>`。
- 目录页（P02）右列每行 = 序号（Consolas 30px 强调色）+ 章名（26px）+ 页码范围（Consolas 20px opacity 0.45）。

## 6. 密度与禁则

- 每页只讲**一个核心观点**；B 区卡片 ≤ 5 张，行列表 ≤ 5 行。
- 占位框内三层文字：编号（Consolas）/ 名称（bold）/ 建议画面（说明）。
- 不出现：官网地址、学校与指导教师、「提高效率 / 加班 / 压榨」类措辞、编造的数据。
- 「智能体」在 P05 首次出现，旁注 *（软件里那个帮你把话变成提醒的小助手）*。
