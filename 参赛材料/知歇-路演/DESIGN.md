# DESIGN.md — 知歇 ZhiXie 路演演示文稿设计稿

> 本文件是本项目的**设计宪法**：画布、配色、字号、母版、密度与页面映射表。逐页生成时严格对照，禁止逐页随机发挥。

---

## 0. 视觉语言声明

本项目采用**纯图形语言（graphic-only）**，全篇不使用摄影 / 插画 / 3D 位图：所有视觉载体为 **SVG 图形 + 巨型数字 + 表格 + 图标**。理由：

1. 作品本身是暗色 + 薄荷绿的系统工具，图形语言与产品视觉同源，风格自然统一；
2. 本 deck 的叙事核心是**架构、校验规则、测试数据、功能对比**——这些都属于结构化 / 抽象 / 低语义元素，正是 SVG 的适用范畴；
3. 避免任何具象场景（人物 / 办公室 / 校园）配图，从而不产生"用几何图形冒充具象主视觉"的问题。

**因此本项目不需要 ImageGen 产物**，`assets/` 目录留空；所有视觉元素在页面内以内联 `<svg>`、`FAIcon`、`Table`、`Text` 实现。

## 1. 画布与母版（写死 px）

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 0–120px | 120px | 主标题 36px bold；左对齐，左边距 64px；标题下方可带一行 16px 副标 |
| **B · 内容区** | 120–660px | 540px（可用高度 540px） | 一切正文、图形、表格、卡片；**禁止挤占 A / C 区** |
| **C · 页脚条** | 660–720px | 60px | 左侧 `知歇 ZhiXie · V1.0.0`；右侧 `NN / 18`；统一 14px 次级色 |
| 页面 padding | 上 20px / 左右 64px / 下 20px | — | A / B / C 均在此 padding 之内 |

**画布**：`1280 × 720px`，16:9。

**高度自检**：`20(上padding) + 100(A区标题) + 540(B区) + 60(C区) + 20(下padding) = 740 > 720`。
→ 实际执行时按：`Slide` 用 `padding: '20px 64px'`，A 区高 **100px**，B 区高 **500px**，C 区高 **60px**，合计 20+100+500+60+20 = **700px ≤ 720px**，余量 20px 作为 A/B 之间的呼吸空间。**每页 B 区元素高度累加必须 ≤ 500px。**

**封面 / 章节扉页 / 结束页**允许自定义版式，可省略 C 区。

## 2. 配色系统（4 个 hex，不再增加）

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| **主色 · 底色** | `#0B1220` | 页面背景、大色块 |
| **辅色 · 面层** | `#1B2740` | 卡片背景、分区面板、表格行 |
| **强调色** | `#4FE0B0` | 仅用于焦点元素：巨型数字、关键结论、序号、进度条、图表高亮 |
| **文本主色** | `#E8EEF7` | 标题与正文 |

**次级文本不引入新 hex**：统一用 `#E8EEF7` + `opacity`（正文 0.72 / 注解 0.55 / 页脚 0.42）。
**描边**：`rgba(232,238,247,0.14)`（= 文本主色低透明度，不新增色值）。
**禁止色**：不使用纯黑 `#000`、不使用纯红 / 纯绿 / 金色。

### 2.1 色彩面积分配

| 色彩角色 | 面积占比 | 说明 |
| :--- | :--- | :--- |
| 主色（背景） | 55–75% | 页面底色 |
| 辅色（面层） | 15–30% | 卡片、面板、表格 |
| 强调色 | **常规页 ≤ 8%**；Hero 页可到 15–18% | 只出现在焦点元素上 |
| 中性（文本 / 描边） | 剩余 | — |

**刻意制造差异的页面**：P12（强调色 18%，巨型数字爆发）、P07（强调色 15%，架构图主线）与 P04 / P13（强调色 ≤ 5%，信息密集）。禁止全篇色彩比例雷同。

### 2.2 渐变与半透明策略

- **渐变的唯一用法**：强调色渐变条 `linear-gradient(135deg, #4FE0B0 0%, #2E9E8F 100%)`，用于①卡片顶部 4px 装饰条；②P12 巨型数字描边；③P01 封面光弧。**全篇渐变出现次数 ≤ 6**。
- **半透明**：卡片底 `rgba(232,238,247,0.04)`；高亮结论条 `rgba(79,224,176,0.10)`；章节扉页巨型编号用 `stroke: rgba(79,224,176,0.22)` 描边不填充。
- **卡片浮起**：`boxShadow: '0 6px 24px rgba(0,0,0,0.35)'`。**仅用于卡片组**，全篇 ≤ 8 处。

## 3. 字体系统（2 套字族）

| 用途 | 字族 | 说明 |
| :--- | :--- | :--- |
| 标题 / 正文 / 注解 | `微软雅黑` | 中文主力字族；Windows 原生、macOS 会回退到系统黑体，布局尺寸不受影响 |
| 巨型数字 / 版本号 / 计数 | `Consolas` | 等宽数字，营造技术规格感；与正文形成明确字族区分 |

| 层级 | 字号 | 字重 | 行高 | 字距 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 72px | bold | 1.2 | 0 | 仅 P01 |
| 章节大字 | 60px | bold | 1.15 | 0 | P03 / P06 / P11 |
| **巨型数据 / 锚点** | **120px** | **bold** | **1.0** | **-2px** | P12（138）；P18 金句 56px |
| 页面主标题（A 区） | 36px | bold | 1.25 | 0 | 所有 content 页 |
| A 区副标题 | 16px | regular | 1.4 | 0.5px | content 页标题下 |
| 卡片小标题 | 24px | bold | 1.3 | 0 | 卡片头 |
| 正文 | 20px | regular | 1.6 | 0 | 段落 |
| 表格 / 列表正文 | 17px | regular | 1.4 | 0 | 表格、对照表 |
| 引文 / 注解 | 16px | regular | 1.5 | 0 | 洞察框、脚注文字 |
| 页脚 / 页码 | 14px | regular | 1.4 | 0 | C 区 |

**巨型数字必须与正文不同字族（Consolas）+ 不同字重（bold）**，形成尺度跳跃。

## 4. 信息密度门禁

| 页面类型 | 最少元素 | 正文字数下限 | 主视觉占 B 区 |
| :--- | :--- | :--- | :--- |
| 封面 | 主标题 + 副标 + 主视觉 | 20 | ≥ 35% |
| 目录 | 3 条目 + 引导句 | 100（合计） | — |
| 内容页 · 单主题 | 标题 + 正文 + 主视觉 | 180 | ≥ 30% |
| 内容页 · 卡片组 | 标题 + 引导句 + 3 卡 | 每卡 ≥ 100 | — |
| 数据 / 图表页 | 标题 + 主图 + 洞察 | 80 | ≥ 50% |
| 章节扉页 | 章节大字 + 一句小标 | 30 | ≥ 40% |
| 结束页 | 金句 + 落款 | 20 | — |

- **常规内容页留白上限 35%**；Hero 页可到 40–45%（留白围绕焦点元素）。
- **容器填充率 ≥ 85%**：卡片内内容垂直占满，尾部元素用 `marginTop: 'auto'` 或父级 `justifyContent: 'space-between'` 钉底。
- **横向兄弟卡三段对齐**：同一行的卡片，标题块 / 正文块 / 尾部条 的 y 坐标差必须 ≤ 16px。
- **禁止"均匀稀薄"**：每页必须有 ≥ 1 个视觉锚点（≥ 44px 元素，或 ≥ 40% B 区面积的图形）。

## 7. 逐页生成时的自检清单（每页提交前逐项确认）

1. A/B/C 三区齐全，A 区标题位置全篇一致，C 区页脚与页码齐全（封面 / 章节 / 结束页除外）。
2. A 区右侧无任何装饰小图。
3. 本页 L1 主视觉占 B 区 ≥ 30%（Hero 页 ≥ 40%），未用 L3 顶替。
4. 仅使用本文件的 4 个 hex，未引入新色值。
5. 本页留白 ≤ 35%（Hero ≤ 45%）。
6. 本页有 ≥ 1 个视觉锚点（≥ 44px 元素或 ≥ 40% B 区图形）。
7. 与上一页版式不同、视觉重量有明显差异。
8. 强调色只出现在焦点元素，面积比合规。
9. 高度累加 ≤ 700px，内容不溢出。
10. 含关键数据的页必须给出判断（"这意味着什么"），不得只摆数字。
