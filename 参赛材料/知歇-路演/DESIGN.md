# DESIGN.md — 知歇 ZhiXie 路演演示文稿设计稿（使用流程版）

> 本文件是本项目的**设计宪法**：画布、配色、字号、母版、密度、截图占位框规范与页面映射表。逐页生成时严格对照，禁止逐页随机发挥。
> 2026-10-11 随 STORY 全篇改版：**新增截图占位框体系**，页面映射表按新的 18 页结构重排。

## 0. 视觉语言声明

本项目采用**图形语言 + 界面截图**的混合方案：

1. **结构性图形**仍用内联 `<svg>`：流程图、对照表、递减条、光弧、巨型数字、表格——适合表达「关系 / 规则 / 数据」。
2. **凡是讲「软件长什么样、怎么用」的地方，一律用截图占位框**（P04–P14 共 16 处）。理由：本版主线是使用流程与成果展示，真实界面比抽象示意图有说服力得多。
3. 不使用摄影 / 插画 / 3D 素材；不出现具象人物与场景配图。

**占位框不是"缺图"的临时补丁，而是正式版式元素**：它带编号、应放截图名、建议画面说明，作者自行截图替换即可，路演时编号与说明可当图注用。

## 0.1 截图占位框规范（本版新增，全篇统一）

```
外层容器：background 'rgba(79,224,176,0.05)'
          border     '2px dashed rgba(79,224,176,0.55)'
          borderRadius 10
          内部 flexDirection column / justifyContent center / alignItems center / gap 8
内部三层文字（自上而下）：
  ① 编号标签  13px · Consolas · #4FE0B0 · letterSpacing 1   → 「截图 ⑤」
  ② 截图表名  15–16px · bold · #E8EEF7 · opacity 0.92      → 「智能体页 · 解析结果」
  ③ 建议画面  12–13px · #E8EEF7 · opacity 0.5 · 居中 · 可换行 → 「结果区列出 类型 / 时间 / 重复 / 系统操作，并标注来源」
```

**尺寸档位**：

| 档位 | 尺寸 | 用在哪 |
| :--- | :--- | :--- |
| 大框 | 宽 ≥ 520，高 300–420 | P05②、P06④、P10⑨、P11⑪ |
| 中框 | 宽 300–420，高 220–300 | P08⑤⑥⑦、P12⑬⑭、P14⑮ |
| 小框 | 宽 200–300，高 130–200 | P04①、P09⑧、P10⑩、P11⑫、P16⑯ |

**硬规则**：
- 编号 ①–⑯ 全篇唯一、不重复、按页递增；编号与 STORY.md 第四节清单逐条对齐。
- 占位框**必须**带第 ③ 层「建议画面」文字，不能只写「放截图」。
- 同一页内多个占位框尺寸一致（P08 三框、P11 两框、P12 两框）。
- 占位框不计入「色彩面积」的强调色配额（它是低透明度面层）。

## 2. 配色系统（4 个 hex，不再增加）

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| **主色 · 底色** | `#0B1220` | 页面背景、大色块 |
| **辅色 · 面层** | `#1B2740` | 卡片背景、分区面板、表格行 |
| **强调色** | `#4FE0B0` | 仅用于焦点元素：巨型数字、关键结论、序号、占位框描边、图表高亮 |
| **文本主色** | `#E8EEF7` | 标题与正文 |

**次级文本不引入新 hex**：统一用 `#E8EEF7` + `opacity`（正文 0.72 / 注解 0.55 / 页脚 0.42）。
**描边**：`rgba(232,238,247,0.14)`。
**禁止色**：不使用纯黑 `#000`、不使用纯红 / 纯绿 / 金色。

### 2.1 色彩面积分配

| 色彩角色 | 面积占比 | 说明 |
| :--- | :--- | :--- |
| 主色（背景） | 55–75% | 页面底色 |
| 辅色（面层） | 15–30% | 卡片、面板、表格 |
| 强调色 | **常规页 ≤ 8%**；Hero 页可到 15–18% | 只出现在焦点元素上 |

**刻意制造差异的页面**：P14（强调色 18%，巨型数字爆发）、P08（强调色 15%，三张占位框描边）与 P04 / P15（强调色 ≤ 6%，信息密集）。禁止全篇色彩比例雷同。

### 2.2 渐变与半透明策略

- **渐变的唯一用法**：强调色渐变条 `linear-gradient(135deg, #4FE0B0 0%, #2E9E8F 100%)`，用于①卡片顶部 4px 装饰条；②P14 巨型数字下的短条；③P01 封面光弧。**全篇渐变出现次数 ≤ 6**。
- **半透明**：卡片底 `rgba(232,238,247,0.04)`；高亮结论条 `rgba(79,224,176,0.10)`；章节扉页巨型编号用 `stroke: rgba(79,224,176,0.22)` 描边不填充。
- **卡片浮起**：`boxShadow: '0 6px 24px rgba(0,0,0,0.35)'`。仅用于卡片组，全篇 ≤ 8 处。

## 4. 信息密度门禁

| 页面类型 | 最少元素 | 正文字数下限 | 主视觉占 B 区 |
| :--- | :--- | :--- | :--- |
| 封面 | 主标题 + 副标 + 主视觉 | 20 | ≥ 35% |
| 目录 | 3 条目 + 引导句 | 100（合计） | — |
| 内容页 · 单主题 | 标题 + 正文 + 主视觉 | 180 | ≥ 30% |
| 内容页 · 流程页 | 标题 + 话术条 + 3 步 | 150 | ≥ 45% |
| 数据 / 图表页 | 标题 + 主图 + 洞察 | 80 | ≥ 50% |
| 章节扉页 | 章节大字 + 一句小标 | 30 | ≥ 40% |
| 结束页 | 金句 + 落款 | 20 | — |

- **常规内容页留白上限 35%**；Hero 页可到 40–45%。
- **容器填充率 ≥ 85%**：卡片内内容垂直占满，尾部元素用 `marginTop: 'auto'` 或父级 `justifyContent: 'space-between'` 钉底。
- **横向兄弟元素三段对齐**：同一行的占位框 / 卡片，标题块 / 正文块 / 尾部条 的 y 坐标差 ≤ 16px。
- **禁止"均匀稀薄"**：每页必须有 ≥ 1 个视觉锚点（≥ 44px 元素，或 ≥ 40% B 区面积的图形 / 占位框）。

## 7. 逐页生成时的自检清单（每页提交前逐项确认）

1. A/B/C 三区齐全，A 区标题位置全篇一致，C 区页脚与页码齐全（封面 / 章节 / 结束页除外）。
2. A 区右侧无任何装饰小图。
3. 本页 L1 主视觉占 B 区 ≥ 30%（Hero 页 ≥ 40%），未用 L3 顶替。
4. 仅使用本文件的 4 个 hex，未引入新色值。
5. 本页留白 ≤ 35%（Hero ≤ 45%）。
6. 本页有 ≥ 1 个视觉锚点。
7. 与上一页版式不同、视觉重量有明显差异。
8. 强调色只出现在焦点元素，面积比合规。
9. 高度累加 ≤ 500px（B 区），内容不溢出。
10. **本页是否出现技术名词？若不是 P15 / P16，必须改成人话。**
11. **本页占位框编号是否与 STORY 第四节清单一致？三层文字是否齐全？**
12. 含关键数据的页必须给出判断（「这意味着什么」），不得只摆数字。
