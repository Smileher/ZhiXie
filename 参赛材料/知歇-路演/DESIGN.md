> 2026-10-12 重构：30 页 → **38 页**，整体色调由深色改为**亮色为主**（浅底白卡深字，薄荷绿作强调）。

## 0. 视觉语言

**图形语言 + 界面截图**混合：
1. 结构性图形用内联 `<svg>`：架构、流程、对照、递减条、光弧、巨型数字、表格。
2. 讲「软件长什么样、怎么用」的页面用**截图占位框**（10 处）。
3. 目标用户群体章节用**数据图占位框**（3 处），标注"建议补充真实调研数据"，**严禁编造数字**。
4. 不使用摄影 / 插画 / 3D 素材。

## 2. 配色系统（亮色 · 5 个 hex，不再增加）

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| 主色 · 底色 | `#F5F9FC` | 页面背景（亮） |
| 辅色 · 面层 | `#FFFFFF` | 卡片背景、面板（白卡） |
| 强调色（深） | `#0D9488` | 序号、标题强调、占位框描边、关键结论（在浅底上对比足够） |
| 强调色（亮） | `#4FE0B0` | 高亮卡填充、光弧、Hero 装饰条（配深色字） |
| 文本主色 | `#0B1220` | 标题与正文 |

次级文本用 `#0B1220` + `opacity`（正文 0.62 / 注解 0.5 / 页脚 0.4）。描边 `rgba(11,18,32,0.10)`；卡片描边 `1px solid rgba(11,18,32,0.10)`；高亮卡 `background rgba(79,224,176,0.16)` + `border 1px solid rgba(13,148,136,0.35)`。

- 强调色（深 #0D9488）常规页用于序号/小标题；亮薄荷绿仅作少量填充，避免大面积导致发飘。
- 渐变仅用于：Hero 光弧、章节大数字下方短条；全篇 ≤ 6 次。
- 卡片浮起 `boxShadow: '0 6px 20px rgba(11,18,32,0.08)'`，全篇 ≤ 6 处。

字族：`微软雅黑`（标题 / 正文）；`Consolas`（巨型数字、版本号、占位框编号）。

| 层级 | 字号 | 换算 | 用途 |

| 封面主标题 | 76px | 57pt | 仅 P01 |
| 章节大字 | 64px | 48pt | 8 个章扉 |
| 巨型数字 | 160px | — | P28（138） |
| **页面主标题（A 区）** | **46px** | **34.5pt ≥ 32pt** | 所有 content / 章扉 |
| **A 区副标题（核心观点）** | **28px** | **21pt ≥ 20pt** | content 页标题下 |
| 卡片小标题 | 34px | 25.5pt | 卡片头 |
| **正文 / 列表 / 表格** | **28px** | **21pt ≥ 20pt** | 段落、表格单元格 |
| 结论 / 强调句 | 30–32px | 22.5–24pt | 高亮条内 |
| 巨型数字注解 | 30px | 22.5pt | P28 数字旁 |

**红线**：任何一页都不得出现 < 22px 的文字；正文类文字不得 < 28px。

## 4. 信息密度门禁（38 页版）

- 每页**只讲一个核心观点**，A 区副标题就是这一页的观点句。
- 每页正文元素 **≤ 5 个**；卡片 / 列表行 / 表格行合计不超过 6 行。
- 表格**最多 6 行**（含表头）；一页只放一张表或一个图。
- **常规内容页留白 ≥ 30%**；Hero / 章扉 35–45%。
- 每页必须有 ≥ 1 个视觉锚点（≥ 44px 元素，或 ≥ 40% B 区面积的图形 / 占位框）。
- 同一页不并列两个图表；需要对照时左文右图。

## 7. 逐页自检清单

1. A/B/C 三区齐全，A 区 124px、B 区 476px、C 区 60px（封面 / 扉页 / 结束页除外）。
2. **本页最小字号 ≥ 22px；正文 ≥ 28px；标题 = 46px。**
3. 本页只有一个核心观点，且写在 A 区副标题里。
4. 正文元素 ≤ 5 个；表格 ≤ 6 行；一页一张图 / 一张表。
5. 留白 ≥ 30%（Hero / 章扉 ≥ 35%）。
6. 仅使用 5 个 hex + 必要的 rgba；
7. B 区高度累加 ≤ 476px，无溢出。
8. **本页是否出现技术名词？若不在 P10 / P17–P23，必须改成人话。**
9. 占位框编号与 STORY 第四节一致，三层文字齐全；数据图占位须含"建议补充真实调研数据"。
10. 含数字的页面必须给出"这意味着什么"。
