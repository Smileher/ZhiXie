## 二、逐页大纲

### P1 · 封面
- 标题：**知歇 ZhiXie**
- 副标题：知时而歇，张弛有度 —— 会听人话的桌面休息提醒
- 底部信息条：无锡开放大学 ｜ 创新主赛道 · AIGC 创新组 ｜ 指导教师：王敏
- 视觉：应用主界面截图 + 新月牙 logo

### P2 · 问题：为什么需要知歇
- 场景化开场："你上一次连续坐在电脑前是多久？"
- 现有工具的两个痛点（左右对照排版）：
  - **配置繁琐**——时间选择器、重复规则、多级菜单，想设一个提醒先要学一套概念
  - **提醒机械**——固定文案反复弹出，几轮之后大脑自动过滤
- 一句话转折：不是用户不想休息，是工具不好用。

### P3 · 解决方案（项目概述）
- 一句话定义：**融合智能体的桌面休息提醒工具**
- 三个关键词胶囊：一句话生成规则 ｜ 云端 + 本机双通道 ｜ 数据全在本机
- 双平台徽标：Windows x64 / ARM64 · Apple Silicon macOS

### P4 · 应用场景
- 四宫格，每格一张界面或弹窗截图：
  1. 高校机房与实训室（统一休息节律、可定制校风文案）
  2. 备考与自学（间隔自由、不限于 25 分钟）
  3. 远程办公与自由职业（可附加锁屏 / 关机形成约束力）
  4. 家庭电脑（到点提醒并锁屏）

### P5 · 目标用户群体
- 主画像卡片：18—30 岁学生与年轻职场人，日均电脑使用 4 小时以上
- 次画像卡片：家长（孩子用电脑时段管理）
- 共同特征一行：**知道该休息，但专注时忘记；嫌配置麻烦，愿意"说一句话"**

### P6 · 核心体验演示（现场 Demo / 备用动图）
- 左侧提示输入话术：**"每周一三五下午三点半提醒我站起来活动，顺便锁屏"**
- 右侧展示解析结果表单：类型=每周 ｜ 时间=15:30 ｜ 重复=周一、周三、周五 ｜ 系统操作=锁屏
- 箭头 → 一键「加入时间锚点」→ 弹窗触发画面
- 断网演示分支：拔网线再解析一次，提示"云端不可用，已自动切换本机规则引擎"
- **若现场不便联网演示，此页放 3 张连续截图 + 一段 15 秒录屏**

### P7 · 智能体开发过程 · 双通道架构
- 架构图：用户输入 → 云端大模型 ／ 本机规则引擎 → **统一校验层** → 提醒数据
- 强调三个设计原则：云端提升上限 · 本机保底可用 · **校验优先落库**

### P8 · 智能体开发过程 · 本机规则引擎
- 四类高频表达的解析对照表：
  - 中文数字时间：下午三点 → 15:00
  - 相对时间：30分钟后 → 当前时间 +30 分钟
  - 连写周几：每周一三五 → [周一, 周三, 周五]
  - 系统操作词：关机 / 重启 / 锁屏
- 右下角小字标注：纯 Rust 实现，零外部依赖，断网可用

### P9 · 智能体开发过程 · 校验层（本项目的"防幻觉"设计）
- 一句话论点：**大模型可以自由发挥，但只有通过白名单校验的字段才能落库**
- 表格：类型 / 时间 / 星期 / 日期 / 系统操作 五类字段的合法取值范围与非法处理方式
- 佐证：单元测试 `cloud_drafts_are_validated` 构造脏数据，验证全部被过滤

### P10 · 智能体开发过程 · 低代码 / 无代码
- 两档对照：
  - 普通用户：装完即用，零配置、零联网
  - 进阶用户：三格表单（接口地址 / 模型名 / 密钥）即完成接入，**全程无代码**
- 强调：结果可视化确认后才写入

### P11 · 实施计划
- 五阶段横向时间线：原型期 → 工程期 → 智能期 → 验证期 → 推广期
- 前四阶段打勾，推广期高亮标注"进行中"
- 每阶段一句话产出

### P12 · 工程质量（技术可行性的硬证据）
- 大数字排版：**138** 项自动化测试全绿（前端 77 + Rust 61）
- 双平台构建通过（Windows x64/ARM64 + Apple Silicon DMG）
- 三个技术保障标签：原子写入 ｜ CSP 安全策略 ｜ 并发时序测试

### P13 · 数据安全与隐私
- 三个"零"：零账号 ｜ 零遥测 ｜ 默认零联网
- 数据流向说明：所有数据留在本机配置目录（`zhixie.json` / `agent-config.json`）
- 云端最小化：启用后仅发送用户输入的那一句话

### P14 · 创新点（上）
- **一句话生成提醒规则**：把"配置"变成"对话"
- **云端 + 本机双通道**：理解力与可用性兼得，切换无感

### P15 · 创新点（下）
- **校验优先的落地设计**：AI 幻觉不污染用户数据
- **人机协同的开发范式**：学生独立主导，AIGC 辅助实现 + 138 项测试闭环
- **温和的休息倡议**：反效率焦虑的产品立场

### P16 · 应用价值
- 三列卡片：健康价值 ｜ 教育价值 ｜ 推广价值
- 一句收束：零账号、零联网（默认）、零广告，适合机房批量部署

## 三、制作与呈现建议

| 项目 | 建议 |
| --- | --- |
| 配色 | 沿用应用主色调（薄荷绿系），深色底 + 高对比文字；与产品视觉保持一致 |

## 四、现场风险预案

| 风险 | 预案 |
| --- | --- |
| 现场断网 | 恰好可作为"本机规则引擎兜底"的演示素材，先演示断网解析再恢复 |
| 投影分辨率低 | 关键页面字号不小于 20pt，避免表格过密（P9 / P17 可拆成两页） |
| 时间被压缩到 5 分钟 | 优先保留 P2 / P6 / P7—P9 / P12 / P14—P15，压缩 P4 / P5 / P11 |
| 评委要求现场操作 | 提前在本机运行一份已配置好的实例，避免依赖现场电脑 |
| 提问超出准备范围 | 先复述问题、确认理解，再回答；不确定的部分明确说明后续验证计划 |
