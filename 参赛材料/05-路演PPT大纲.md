## 二、逐页大纲

### P1 · 封面
- 标题：**知歇 ZhiXie**；副标：知时而歇，张弛有度
- 一句话：说一句话，它就把提醒给你设好，到点把人从屏幕前拉开
- **绿色对勾一行：已经做完 · 官网可直接下载安装**（完成度从第一页就开始立）
- 底部：创新主赛道 · AIGC 创新组

### P2 · 目录
- 三章：01 这是什么、给谁用（P3–P6）｜02 怎么用：从一句话到弹窗（P7–P12）｜03 做得怎么样（P13–P17）
- 左侧三个提问：它是干嘛的？具体怎么用？做得怎么样？

### P3 · 章扉 01 这是什么、给谁用
- 导语：不先讲道理，先说清楚这是个什么东西、从哪儿能拿到、打开之后长什么样。

### P4 · 不是不想休息，是工具不好用
- 毛病一 · 设置太麻烦：想设「每周一三五下午三点半」，得先把一整套表单弄明白
  - **截图占位 ①**：传统提醒工具的设置界面（时间选择器 + 重复规则 + 多级菜单）
- 毛病二 · 提醒看腻了：同一句固定文案弹几次，眼睛就自动跳过去
- 讲稿要点：门槛不在点几下，而在要先学会「单次/每天/每周/每月」这套说法——这是后面"说一句话"的伏笔。

### P5 · 它是什么，去哪下载
- **截图占位 ②**：知歇官网首页（产品名 + 口号 + 下载按钮）
- **截图占位 ③**：安装包 / 安装完成界面
- 右侧三个关键词：说一句话就设好 ｜ 没网也照样能用 ｜ 数据在自己电脑里，不用注册
- 收束：Windows 和 macOS 都能装，官网直接下载，装完打开就能用
- 讲稿要点：第一句定义里第一次出现"智能体"，必须带一句人话解释——"就是那个帮你把话变成提醒的小助手"。

### P6 · 打开软件，能看到什么
- **截图占位 ④**：主界面全貌（停在「休息节律」页，顶栏五个胶囊导航完整可见）
- 右侧五个入口各一句：休息节律 / 时间锚点 / 智能体 / 偏好调校 / 关于
- 讲稿要点：这页就是"使用说明书的一页"，评委不看演示也能知道软件长什么样。

### P7 · 章扉 02 怎么用：从一句话到弹窗
- 导语：这一章是全篇重点，跟着屏幕走一遍。

### P8 · 一句话建提醒，只要三步 ★
- 顶部话术条：「每周一三五下午三点半提醒我站起来活动，顺便锁屏」
- 三张截图占位横排：
  - **⑤ 输入一句话**（智能体页，输入框 + 模式胶囊）
  - **⑥ 解析结果**（四个字段 + 来源标注）
  - **⑦ 时间锚点页 · 已加入**（列表顶部新锚点 + 下次触发时间）
- 三步：说一句话 → 看结果 → 点一下加入
- 收束条：全程没填过一张表单
- 讲稿要点：若现场演示，此页可边讲边切真实软件；截图占位即演示失败时的兜底。

### P9 · 说人话就行
- 五行对照表（你说的 → 软件理解成）：每天下午三点喝水 / 30分钟后接水 / 每周一三五 17:30 锁屏 / 明早八点交作业 / 晚上十一点锁屏睡觉
- **截图占位 ⑧**：任意一条解析结果
- 左栏：不用套模板、不用背关键词；真没听懂的句子会当成单次提醒、原话留作标题，不报错也不丢
- 讲稿要点：挑两行念就行，别逐行念表。

### P10 · 到点了，会怎么样
- **截图占位 ⑨**：全屏休息弹窗（大图）
- 右侧三块：弹的是什么（自己写的那句话，底图配色可换、实时预览）｜ 两个选择（稍后提醒 / 结束）｜ **要锁屏关机时留 60 秒反悔**（高亮）
- **截图占位 ⑩**：弹窗右下角 60 秒倒计时
- 讲稿要点：60 秒反悔是"约束力"和"安全感"的平衡点，值得单独强调一句。

### P11 · 平时怎么用
- **截图占位 ⑪**：休息节律页（间隔 + 进度条）
- **截图占位 ⑫**：智能体页 · 休息建议卡片
- 下方两块说明：休息节律默认每 40 分钟一次、进度条可见 ｜ 休息建议按间隔与已提醒次数给一句能马上做的事
- 讲稿要点：这页回答"除了定时提醒，平时还有什么用"。

### P12 · 断网也照样用
- 上：没网的时候软件自己顶上——**截图占位 ⑬**（「云端不可用，已自动切换本机规则引擎」提示）
- 下：想更聪明就填三个格子（地址 / 模型名 / 密钥），不用写代码——**截图占位 ⑭**
- 收束：接上了更聪明，不接照样好用；两条路的结果都会先过一遍检查
- 讲稿要点：把"断网"讲成优点而不是缺陷；"过一遍检查"是 P16 的伏笔。

### P13 · 章扉 03 做得怎么样
- 导语：用看得见的东西回答——做完了多少、检查得有多严、跟常用工具有什么不一样。

### P14 · 已经做完：能下载、能装、能用 ★
- 巨型数字 **138** 项自动检查全部通过（界面部分 77 + 核心逻辑 61，通过率 100%）
- **截图占位 ⑮**：官网下载页（两个下载入口同框）
- 四个标签：两个平台都能装 ｜ 官网可直接下载 ｜ 中英双语 ｜ 不用注册账号
- 讲稿要点："每改一次代码就自动跑一遍，有一项不过这次改动就不算完"——完成度由检查保证，不靠演示运气。

### P15 · 技术原理速览（技术名词集中页之一）
- 用什么做的：Tauri 2 + Vue 3 + TypeScript + Rust，同一套代码出双平台
- 一句话怎么变成提醒：联网走网上大模型，没网走自带规则，结果都要过校验
- 数据怎么存：本机一个文件，先写临时文件再替换（原子写入），没有服务器
- 讲稿要点：全篇技术名词只在这一页和下一页；语速可以稍慢，但别展开。

### P16 · AI 说的，软件会再核一遍（技术名词集中页之二）
- 对照表：五类内容各认什么、不合规怎么办（退回默认 / 丢掉 / 置空 / 用原话）
- **截图占位 ⑯**：解析结果页（标注来源）
- 结论条：大模型只负责提建议，能不能写进去软件说了算；表单确认后才写入，人一直在最后一道
- 讲稿要点：这是"防 AI 出错"的核心设计，用一句话讲透——"AI 可能胡说，但胡说的东西写不进你的提醒列表"。

### P17 · 五个不一样的地方
- 左：01 说一句话就设好 ｜ 02 没网也能听懂 ｜ 03 AI 说的先核一遍 ｜ 04 一个人 + AI 助手做出来（138 项检查兜底）｜ 05 立场是让你休息
- 右：和常用工具比（建提醒 / 断网 / 锁屏关机 / 要不要账号）+ 一句价值收束
- 讲稿要点：别用"创新点一、创新点二"的腔调念，用"我们跟别人不一样的地方是……"的口气说。

### P18 · 结束页
- 金句：知时而歇，张弛有度
- 一行：已经做完，官网可直接下载安装；Windows 和 macOS 都能用
- 一行：我们希望做的，不是一个催你干活的工具，而是一个提醒你停下来的工具
- 落款：创新主赛道 · AIGC 创新组

## 四、现场风险预案

| 风险 | 预案 |
| --- | --- |
| 现场断网 | 恰好是 P12 的演示素材：先演示断网解析，再恢复网络 |
| 软件现场启动失败 | 改用 P8 / P10 截图占位讲解，并播放 15 秒录屏 |
| 投影分辨率低 | 关键页字号不小于 16pt；表格页（P16）可只念不细看 |
| 时间被压缩到 5 分钟 | 保留 P1 / P5 / P8 / P10 / P14 / P17，其余快翻 |
| 评委要求现场操作 | 提前在本机运行一份已配置好的实例，不依赖现场电脑 |
| 提问超出准备范围 | 先复述问题、确认理解，再回答；不确定的部分明确说明后续验证计划 |
