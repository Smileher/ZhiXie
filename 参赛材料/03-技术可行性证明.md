# 知歇 ZhiXie · 技术可行性证明

> 作品版本：1.0.0
> 验证环境：Apple Silicon macOS（Apple M 系列）+ Windows 10/11（x64、ARM64）
> 结论：**架构清晰、关键路径均有测试覆盖、双平台构建与真机运行全部通过，技术方案可行。**

---

## 一、总体架构

知歇为 Tauri 2 桌面应用，前端界面与系统核心分层清晰：

```
┌──────────────────────────────────────────────────────┐
│  前端层（Vue 3 + TypeScript + Vite）                   │
│  App.vue（状态与 IPC 编排）                            │
│  休息节律 / 时间锚点 / 智能体 / 偏好调校 / 关于          │
│  ReminderPopup（弹窗）· PopupBackground（底图）        │
└──────────────────────┬───────────────────────────────┘
                       │ Tauri IPC（类型化命令，共 27 个）
┌──────────────────────▼───────────────────────────────┐
│  核心层（Rust）                                        │
│  调度器 · 提醒队列 · 弹窗窗口管理 · 系统操作             │
│  系统通知 · 开机自启 · 数据持久化 · 智能体解析           │
│  i18n（中英）· browser（桌面策略）                      │
└──────────────────────────────────────────────────────┘
                       │
┌──────────────────────▼───────────────────────────────┐
│  本机存储（应用配置目录，原子写入）                      │
│  zhixie.json（设置 + 锚点）· agent-config.json（智能体）│
│  popup-background.img（弹窗底图）                      │
└──────────────────────────────────────────────────────┘
```

**分层原则：**

- 调度、时间计算、系统操作、文件读写**全部在 Rust 侧完成**，前端只负责呈现与交互，避免把关键时序逻辑放在 WebView 中；
- 数据以 JSON 形式**原子写入**本机配置目录（先写临时文件再替换，避免写入中断导致数据损坏）；
- 智能体配置独立存放在 `agent-config.json`，与用户数据文件隔离，互不影响。

## 三、关键技术点与实现依据

### 3.1 自然语言解析（智能体核心）

- **云端通道**：通过 HTTPS 调用 OpenAI 兼容接口，系统提示词约束模型输出固定字段 JSON，`temperature 0.2` 保证稳定性，**40 秒超时保护**；
- **本机通道**：纯 Rust 实现的规则引擎，无需任何外部依赖，覆盖中文数字、相对时间、重复规律、系统操作四类高频表达；
- **校验层**：`validate_draft` 对所有来源的解析结果做白名单校验（单元测试 `cloud_drafts_are_validated` 验证非法类型 / 非法时间 / 越界日期均被正确过滤）。

**代码位置**：`src-tauri/src/agent.rs`（738 行，含 8 项单元测试）

**智能体相关单元测试清单：**

| 测试用例 | 验证点 |
| --- | --- |
| `local_parser_understands_daily_time` | 「每天下午三点」→ `daily` `15:00` |
| `local_parser_understands_weekdays` | 「每周一三五 17:30」→ `weekly` `[1,3,5]` + 识别锁屏 |
| `local_parser_understands_relative_minutes` | 「30分钟后」→ 单次提醒且无固定时刻 |
| `local_parser_understands_power_action` | 「关机 / 重启」→ 系统操作识别 |
| `local_parser_falls_back_to_once_without_keywords` | 无关键词句子回落为单次提醒且保留原句为标题 |
| `cloud_drafts_are_validated` | 非法类型 / 时间 / 星期 / 日期 / 系统操作被过滤回落 |
| `json_extraction_tolerates_code_fences` | 大模型返回带 ``` 包裹或夹杂文字时仍能提取 JSON |
| `local_advice_escalates_with_work_time` | 休息建议随连续时长升级 |

### 3.2 调度与提醒时序

- Rust 侧常驻调度器线程按秒轮询到期锚点，形成**提醒队列**，同一时刻只展示一条弹窗，避免多个弹窗互相覆盖；
- **弹窗状态机**有明确幂等约束：延迟到达的旧触发不能覆盖新触发；`Escape` 关闭不会重复隐藏前端状态；
- 系统操作（锁屏 / 关机 / 重启）触发后进入 **60 秒可撤销倒计时**，倒计时期间可取消；执行失败时保留弹窗并提供重试。

### 3.3 数据完整性

| 机制 | 实现 |
| --- | --- |
| 原子写入 | 先写临时文件，成功后再替换目标文件；失败时清理残留临时文件（测试 `atomic_write_replaces_content_and_cleans_failed_replacements`） |
| 版本校验 | 数据文件带 `version` 字段（当前为 6）；版本不匹配时**先备份旧文件再重建默认值**，不静默丢弃用户数据 |
| 导入校验 | 导入时必须为 JSON 且为当前版本的有效数据结构（测试 `imports_require_json_files_and_valid_current_data`） |
| 图片处理 | 弹窗底图有体积边界校验，超限或写入失败时保留原图（测试 `image_limit_accepts_boundary_and_preserves_existing_image_on_failure`） |

### 3.4 跨平台一致性

| 能力 | Windows | macOS |
| --- | --- | --- |
| 提醒调度与弹窗 | WebView2 | WKWebView（私有 API 实现透明弹窗） |
| 系统操作 | 系统命令封装 | 系统命令封装 |
| 开机自启 | 注册表 + 启动代理 | 启动代理（LaunchAgent） |
| 通知 | 系统通知（notify-rust） | 系统通知中心 |
| 主题跟随 | 系统主题监听 | 原生标题栏透明 + 背景色同步 |

> macOS 的弹窗透明依赖 Tauri 的 `macos-private-api` 特性；本作品通过 DMG 直接分发、不上架 Mac App Store，符合平台授权要求。

### 3.5 桌面环境策略

前端通过 CSP 限制资源加载来源，并由 Rust 侧策略性屏蔽浏览器类快捷键与右键菜单，防止用户把桌面应用当作浏览器误操作；该策略有专项测试（`browser-policy`）。

## 五、安全与隐私

- **不采集任何用户数据**，无遥测、无广告 SDK；
- **默认完全离线可用**；云端智能体为用户主动开启，密钥仅存本机配置文件；
- **最小化外发数据**：云端仅发送用户输入的那一句话，不携带任何本机数据（不发送提醒列表、不发送设置、不发送设备信息）；
- **前端 CSP 限制**资源加载来源，桌面快捷键与右键菜单被策略性屏蔽（防误操作），相关策略有专项测试；
- **数据可迁移可清除**：用户可随时导出 / 导入 / 重置全部数据。

## 七、开发环境要求与复现步骤

**基础环境**：

- Node.js 22+ 与 pnpm
- Rust stable 工具链
- Windows：MSVC、Visual Studio 生成工具（C++ 桌面开发）、WebView2
- macOS：Xcode Command Line Tools

**复现步骤**：

```sh
pnpm install                                        # 安装前端依赖
pnpm tauri:dev                                      # 运行桌面应用

pnpm build                                          # 类型检查 + 前端构建
pnpm test                                           # 前端单元测试（77 项）
cargo test --manifest-path src-tauri/Cargo.toml     # Rust 单元测试（61 项）
pnpm tauri:build                                    # 打包安装包
```

> 运行 `pnpm tauri:dev` 前，请先从托盘菜单退出已运行的副本（应用启用了单实例保护）。
