# 知歇 ZhiXie · 技术可行性证明

---

## 一、总体架构

知歇为 Tauri 2 桌面应用，前端界面与系统核心分层清晰：

```
┌────────────────────────────────────────────┐
│  前端（Vue 3 + TypeScript + Vite）          │
│  事件视图 / 休息视图 / 设置视图 / 智能助手 / 关于 │
└──────────────┬─────────────────────────────┘
               │ Tauri IPC（类型化命令）
┌──────────────▼─────────────────────────────┐
│  核心（Rust）                               │
│  调度器 / 提醒队列 / 弹窗窗口 / 系统操作        │
│  通知 / 自启动 / 数据持久化 / 智能体解析        │
└────────────────────────────────────────────┘
```

- 调度、时间计算、系统操作、文件读写全部在 Rust 侧完成，前端只负责呈现与交互；
- 数据以 JSON 形式原子写入本机配置目录（先写临时文件再替换，避免写入中断导致数据损坏）；
- 智能体配置独立存放在 `agent-config.json`，与用户数据文件隔离，互不影响。

## 二、关键技术点与实现依据

### 2.1 自然语言解析（智能体核心）

- 云端通道：通过 HTTPS 调用 OpenAI 兼容接口，系统提示词约束模型输出固定字段 JSON，`temperature 0.2` 保证稳定性，40 秒超时保护；
- 本机通道：纯 Rust 实现的规则引擎，无需任何外部依赖，覆盖中文数字、相对时间、重复规律、系统操作四类高频表达；
- 校验层：`validate_draft` 对所有来源的解析结果做白名单校验（单元测试 `cloud_drafts_are_validated` 验证非法类型/非法时间/越界日期均被正确过滤）。

**代码位置**：`src-tauri/src/agent.rs`（约 560 行，含测试）

### 2.2 跨平台一致性

| 能力 | Windows | macOS |
| --- | --- | --- |
| 提醒调度与弹窗 | WebView2 | WKWebView（私有 API 实现透明弹窗） |
| 系统操作 | 系统命令封装 | 系统命令封装 |
| 自启动 | 注册表 + 启动代理 | 启动代理（LaunchAgent） |
| 通知 | notify-rust | 系统通知中心 |
| 主题跟随 | 系统主题监听 | 原生标题栏透明 + 背景色同步 |

### 2.4 安全与隐私

- 不采集任何用户数据，无遥测、无广告 SDK；
- 默认完全离线可用；云端智能体为用户主动开启，密钥仅存本机；
- 云端仅发送用户输入的那一句话，不携带任何本机数据；
- 前端 CSP 限制资源加载来源，浏览器类快捷键与右键菜单被策略性屏蔽（防误操作），相关策略有专项测试（browser-policy）。

## 四、开发环境要求

- Node.js 22+、pnpm、Rust stable；
- Windows：MSVC、Visual Studio 生成工具（C++ 桌面开发）、WebView2；
- macOS：Xcode Command Line Tools。

复现步骤：

```sh
pnpm install
pnpm tauri:dev      # 运行
pnpm build && pnpm test
cargo test --manifest-path src-tauri/Cargo.toml
```
