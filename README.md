# 知歇 ZhiXie

> 知时而歇，张弛有度。

一款面向 Windows 与 macOS 的桌面休息提醒工具，内置智能体：用一句话描述需求，就能生成可用的提醒规则；网络不可用时自动切换到本机规则引擎，功能不中断。

## 功能

- **休息提醒**：可自定义间隔与提示语，支持稍后提醒、全屏或窗口化弹窗。
- **个性化弹窗**：背景图、文案、配色、淡入效果均可调整，内置实时预览。
- **定时提醒**：单次、每天、每周、每月，可附带锁屏、关机、重启，并带 60 秒可撤销倒计时。
- **智能助手**：自然语言生成提醒规则，并依据作息给出休息建议，支持云端大模型与本地规则引擎双通道。
- **桌面集成**：系统托盘、开机自启、深浅主题、中英双语、数据导入导出。

## 智能体设计

| 环节 | 说明 |
| --- | --- |
| 需求解析 | 把「每周一三五下午三点半提醒我站起来活动，顺便锁屏」解析为标题、时间、重复规则与系统操作 |
| 休息建议 | 结合提醒间隔与已触发次数生成个性化建议，避免过度强调效率 |
| 结果校验 | 云端返回字段统一校验后才写入数据，非法取值会被过滤或回落默认值 |
| 离线兜底 | 未配置密钥、网络不通或接口报错时，自动改用本机规则引擎解析 |

默认不联网、不收集任何数据。开启云端能力后，接口地址、模型与密钥仅保存在本机配置文件 `agent-config.json` 中。

## 技术栈

- 桌面容器：Tauri 2
- 界面：Vue 3 + TypeScript + Vite
- 核心逻辑：Rust（调度、通知、窗口、系统操作、本地规则引擎）

数据全部保存在本机，无需注册账号，不依赖外部服务器。

## 开发与验证

```sh
pnpm install
pnpm tauri:dev     # 运行桌面应用

pnpm build         # 类型检查 + 前端构建
pnpm test          # 前端单元测试

cargo test --manifest-path src-tauri/Cargo.toml   # Rust 单元测试
```

Windows 需要 MSVC、Visual Studio 生成工具（C++ 桌面开发）与 WebView2；macOS 需要 Xcode 命令行工具。运行 `pnpm tauri:dev` 前，请先从托盘菜单退出已运行的副本。

## 目录结构

```
src/                    前端界面与文案
src/components/         各功能页组件
src-tauri/src/          Rust 侧逻辑
src-tauri/src/agent.rs  智能体解析与配置
tests/                  前端单元测试
```
